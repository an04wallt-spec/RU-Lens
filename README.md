# RU Lens 0.1.0

Личный локальный Android-переводчик турецкого банковского интерфейса на русский.

## Принцип приватности
- В AndroidManifest отсутствует `android.permission.INTERNET`.
- Нет рекламы, аналитики, Firebase и облачных API.
- Текст экрана не сохраняется.
- Перевод запускается только вручную нажатием плавающей кнопки `RU`.
- Приложение не выполняет нажатия и не вводит данные в банковском приложении.

## Что умеет 0.1.0
- AccessibilityService читает текст, который активное приложение предоставляет Android.
- Плавающая кнопка `RU` перемещается по экрану.
- Нажатие `RU` накладывает русский перевод поверх известных турецких банковских/UI-фраз.
- Повторное нажатие `×` убирает перевод.
- Встроенный словарь находится в `BankDictionary.kt`.

## Ограничение первой версии
Если банковское приложение рисует надписи графически и не предоставляет их Accessibility API, эти надписи пока не переводятся. Для них следующим этапом добавляется полностью локальный OCR.
